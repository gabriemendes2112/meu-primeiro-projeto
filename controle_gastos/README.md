# Controle de Gastos em Python

Projeto desenvolvido para praticar lógica de programação com Python.

## Funcionalidades
- Cadastrar gastos com descrição e valor
- Listar os gastos cadastrados
- Calcular o total gasto
- Encerrar o programa pelo menu

## Tecnologias
- Python

## Objetivo
Praticar estruturas de repetição, condicionais, listas e operações matemáticas.
